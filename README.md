# Dragtionary

드래그하면 문맥에 맞게 해석해 주고, 단어장과 용어집에 모아 시험까지 볼 수 있는 크롬 확장 프로그램입니다.

영어 논문이나 기사를 읽다가 모르는 단어를 만나면 드래그만 하세요. 사전식 번역과 함께, AI가 주변 문장을 읽고 그 문맥에서의 뜻을 설명해 줍니다.

## 기능

- **드래그 번역**: 단어나 문장을 드래그하면 그 자리에 번역이 뜹니다.
- **AI 문맥 해석**: 주변 문장을 함께 읽고 그 문맥에 맞는 뜻과 설명을 보여 줍니다. TYK2, IL-10R 같은 약어와 전문용어도 풀어 줍니다.
- **단어장과 용어집**: 일반 단어는 단어장에, 전문용어는 용어집에 따로 모읍니다. 원문 문장과 출처 링크가 함께 저장됩니다.
- **시험**: 뜻을 직접 쓰면 AI가 채점하고 보충 설명을 해 줍니다. API 키 없이 볼 수 있는 4지선다도 있습니다.
- **PDF 지원**: 자체 PDF 뷰어에서 논문 PDF도 드래그로 해석할 수 있습니다.
- **7개 언어**: 한국어, English, 日本語, 中文(简体), Español, Français, Deutsch. 언어를 고르면 화면과 AI 해석이 함께 그 언어로 바뀝니다. 한국어와 영어 외의 화면 문구는 원어민 검수를 거치지 않았습니다.
- **서버 없음**: 단어장과 설정은 모두 내 브라우저에만 저장됩니다.

## AI 문맥 해석 켜기

기본 번역은 설정 없이 바로 됩니다. AI 문맥 해석과 AI 채점 시험을 쓰려면 Gemini API 키가 필요합니다. 무료 등급으로 충분하고 카드 등록이 필요 없습니다.

1. [Google AI Studio](https://aistudio.google.com/apikey)에 구글 계정으로 로그인합니다.
2. **API 키 만들기**를 눌러 키를 복사합니다.
3. 확장의 시작하기 페이지나 설정 탭에 붙여넣고 연결을 확인합니다.

학교나 회사 계정은 발급이 막혀 있을 수 있습니다. 그럴 때는 개인 Gmail 계정을 쓰세요.

이미 OpenAI나 Claude API 키가 있다면 그 키를 넣어도 됩니다. 어느 서비스의 키인지 자동으로 알아봅니다. 이 두 서비스는 사용한 만큼 요금이 나옵니다.

## 알아둘 점

- **기본 번역**: 구글 번역의 비공식 주소를 사용합니다. 공식 지원되는 방식이 아니어서 예고 없이 동작하지 않게 될 수 있습니다. 그 경우에도 AI 문맥 해석은 계속 동작합니다.
- **무료 등급의 데이터 사용**: Gemini API 무료 등급에서는 보낸 내용이 구글의 제품 개선에 쓰일 수 있습니다. 공개되지 않은 문서에서는 사용에 주의하세요.
- **PDF**: 크롬 기본 PDF 뷰어 안에서는 동작하지 않아 자체 뷰어로 전환해야 합니다. 글자가 이미지로 된 스캔본은 지원하지 않습니다.
- **개인정보**: 자세한 내용은 [PRIVACY.md](PRIVACY.md)를 보세요.

## 비슷한 프로젝트

선택한 글을 AI가 문맥에 맞게 설명해 주는 확장은 이미 여럿 있습니다. Rememberry, Readlang, Clutio, Context Vocab, LingoContext 등이 그 예입니다. Dragtionary는 논문을 읽을 때 필요했던 조합, 곧 드래그 즉시 번역, 문맥 해석, 단어장과 용어집의 분리, AI 채점 시험, PDF 뷰어를 서버 없이 한 확장에 담으려고 만들었습니다.
